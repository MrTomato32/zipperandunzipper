# zipperandunzipper V.1.1
A simple zipper and unzipper.

Make sure you have Python 3.x installed on your system.

#Installation:
Clone the repo:
git clone https://github.com/MrTomato32/zipperandunzipper
cd zipperandunzipper

#Run the script:
python zipper.py
